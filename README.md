# Sales Analytics Dashboard

## Overview

An interactive sales analytics dashboard developed in Microsoft Excel as my first practical project in Data Analytics.

The dashboard transforms sales data into interactive visual insights, making it easier to explore sales and profit performance across different periods, countries, and customer segments.

## Tools & Skills

- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Slicers
- Interactive Dashboard Design

## Dashboard Features

The dashboard provides an overview of:

- Sales performance over time
- Profit performance over time
- Units sold across different years
- Year-over-year changes in sales and profit
- Sales performance by country
- Filtering by year, month, and customer segment using Slicers

## Project Objective

The main objective was to practice analyzing data using Pivot Tables and presenting the results through an interactive and visually clear Excel dashboard.

## Learning Outcomes

This project helped me build practical experience in:

- Analyzing data using Pivot Tables
- Creating meaningful visualizations
- Using Slicers for interactive analysis
- Designing an Excel dashboard
- Turning raw data into a clear visual report
